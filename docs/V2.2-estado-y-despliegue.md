## Seguridad y límites antes de uso real

El estado compartido se guarda en una fila JSONB cerrada por RLS; el cliente no puede escribirla directamente. La función Edge valida las acciones conocidas. Las tablas relacionales originales siguen sin políticas de escritura para clientes. La auditoría SQL registra actor y revisión en la misma transacción.

Faltan pruebas remotas de concurrencia, permisos, invitaciones, correo y recuperación. También falta probar el envío real de emails: el servicio SMTP predeterminado de Supabase restringe destinatarios según la configuración del proyecto. Para invitar personas fuera del equipo de la organización puede ser necesario configurar SMTP propio. La restauración de respaldos compartidos sigue cerrada para evitar reemplazos accidentales; solo se ofrece descarga. El historial financiero del prototipo no se migra automáticamente. No activar datos de negocio antes de completar estas comprobaciones.
